# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

One project-specific addition: many people arriving here are caretakers under real stress, sometimes sharing hard personal context in issues. Treat every story shared in this repo with care, and **never ask reporters to post real patient data** (names, DNI, affiliate numbers, diagnoses) to reproduce a bug — synthetic data from `@kerkit/core/fixtures` is always enough.

Enforcement contact: juanse.hevia@gmail.com.
