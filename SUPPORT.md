# Support

kerkit is maintained by one person. To keep everything in one place and get you
an answer, **support lives in GitHub Issues** — there is a template for each
kind of request. GitHub Discussions is intentionally **not** enabled for launch;
if that changes, this page will point you there.

## Where to go

| I want to… | Go to |
|---|---|
| Report a bug | Open a [Bug report](https://github.com/JuanseHevia/kerkit/issues/new?template=bug_report.yml) |
| Share caretaker domain knowledge (no code) | Open an [Eval scenario](https://github.com/JuanseHevia/kerkit/issues/new?template=eval_scenario.yml) |
| Ask a usage question or request a feature | Open an issue, or see the [contribution lanes](./CONTRIBUTING.md#contribution-lanes) first — new locale packs, prompt/schema changes, and provider adapters are **issue-first** |
| Report a security vulnerability or a PII leak | **Do not open a public issue.** Follow [SECURITY.md](./SECURITY.md) (email `juanse.hevia@gmail.com`, subject `[kerkit security]`) |

## Before you open an issue

- Read the [README](./README.md) quickstart and the [Contributing guide](./CONTRIBUTING.md).
- **Never paste real personal or health data.** Use the synthetic persona kerkit
  ships with — **Marta Pérez**, DNI `12.345.678`, "Obra Social Demo Salud". See
  the [PII rules](./CONTRIBUTING.md#pii-rules-non-negotiable).

## What to expect

This is a pre-1.0 project maintained in spare time. Bug fixes with a test and
Argentine insurer data rows for `@kerkit/pack-argentina` are accepted without
prior discussion; everything else starts with an issue so we can agree on
direction before you build.
